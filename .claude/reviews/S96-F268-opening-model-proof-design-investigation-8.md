## Required model wrapper contract

Keep one concrete wrapper in the existing Native document file. It owns CT_Document and an optional private Arc<()> clone-equality token. Use it for both Document.document and the value inside Parsed.main_document. The token and inner field must be private to that invariant owner. Do not put a Weak or identity token on Parsed itself, and do not change Parsed Arc uniqueness behavior.

Only the actual paired opening seed may mint a token and share it across the existing exact Clone. Ordinary wrapper Clone clones the complete value exactly as before and preserves the optional token. Fresh constructors, raw CT_Document replacements, imports and independent reparses enter unknown state. None/None is never a positive proof. Some tokens prove equality only by Arc pointer identity, not by unit-value equality. Two separately allocated tokens, or two independently equal models, use the old equality fallback. Do not promote a fallback success into a retained proof.

Deref returns only an immutable CT_Document reference. DerefMut clears the optional token before returning any mutable CT_Document reference, including a reference used only for a failed or no-op edit. This automatically covers nested body/run/property access and callbacks. It must not rely on callers remembering an invalidation method. Consuming extraction may return the CT_Document, but must discard proof metadata. It must not return a reusable token or expose a mutable inner field. Moving or cloning an intact wrapper preserves its same-value fact, while a raw replacement constructs unknown state.

Keep the existing semantic PartialEq and diagnostic Debug behavior on the inner model. In particular, do not derive wrapper PartialEq over token presence, and do not make a token shortcut the global equality implementation. Existing code compares models for many authorities other than this cold query, including current writer/source checks at document.rs:25860 and flush readback at29398. A token fast path belongs only at the reviewed query boundary. Parsed.main_document may retain its old immutable CT_Document interface, with a separate private match operation that inspects the two wrappers without reading or parsing anything extra.

The caller scope is wider than one query but mechanically bounded. clone_for_staging at document.rs:24616must preserve the wrapper. Whole replacements from canonicalization at25873, source-piece readback at25893, plain parsing at25905, control publication at `crates/rdocx/src/content_control.rs:254`, revision publication at `crates/rdocx/src/revision.rs:540`, comparison at `crates/rdocx/src/comparison.rs:1448` and field reconstruction at `crates/rdocx/src/field.rs:13468` must construct unknown wrappers when their source is a raw CT_Document. These ownership conversions must be inventoried and checked across all targets. Compilation must expose every incompatible owned escape rather than adding broad conversion traits or public forwarding helpers to hide them.

This arrangement satisfies the structural rule because mutation and proof invalidation become inseparable at the actual value owner. It introduces no new trait, generic type parameter, module, source file, feature or stable public API. Deref and DerefMut are existing traits.
