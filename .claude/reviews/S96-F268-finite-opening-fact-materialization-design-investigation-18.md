## Separate run-path capacity proposal remains unselected

Reserving output capacity equal to paragraph.runs.len and prefix capacity1 would preserve path values and traversal if these are the only changes. Every direct run is still emitted, so runs.len is a lower bound on output length. Controls/revisions can append more and grow normally. Prefix push/pop and each full prefix clone must remain exactly as before. No direct-run semantic fast path, private-owner bypass or replacement of recursive selectors is justified.
