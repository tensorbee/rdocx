# S96 memory omission endpoints, design investigation 2

## Disposition and boundary

The current source supports a finite private omission registry. The registry below is a proposed implementable endpoint contract, not an existing overlay, qualified variant or measurement. Its grouped modes deliberately overlap. Their differences must never be added. Native All and Python All have distinct explicit scopes. The old missing mode count is not reused.

The mandatory counterpart includes all30semantic/provenance DocumentIdentifiers fields, the live document/package models and source-preserving package metadata, namespace classifications, publication/index/scope state and numbering reconciliation. Those are not omission targets. Private Field and Source identity rules remain authoritative. No extra AST, history, parser or allowance is proposed.

Concrete implementation obligations remain for borrowed-result caches and the binding's active-piece assumptions. They are described below rather than hidden behind an offer-off flag. No omission variant is ready for RSS interpretation before implementation, equivalence and calibration review.

## What an omission means

Use one concrete private startup enum with the named modes below, Normal, NativeAll and PythonAll. A diagnostic-only installer rejects unknown names and every second installation, including the same name. Install before fixture access or document construction. All threads observe the same immutable process policy. No environment lookup, mutable mask or phase-time toggling selects retention. The complete resolved endpoint set is printed with source/artifact identity before measurement.

At an omitted endpoint, prevent optional deep copies, Arc/Weak/cell/key construction and installation before allocating them. Also suppress lazy installation, clone/carry retention and every aliasing producer. Do not allocate the original payload and merely disable lookup. Existing mandatory transient reads/writes/scans may still allocate and are reported as transient. A transient record needed by actual canonical/Source work dies before the measured phase ends and is never installed in a document, opening, binding or operation-history owner. Fixed inline empty slots and required empty owner containers remain disclosed. This is omission of the declared retained owner, not a claim that all temporary allocation disappears.

The registry is global by physical owner kind. It is not limited to whichever writer record happens to be offered first. A cache reachable through Document.main_part_blocks, MainBodyScans.serialized, Parsed.source_blocks, source-normalization correspondence or a carried clone is subject to the same endpoint rule. Graph observation counts shared payloads once and ownership edges separately. Removing one Arc edge is not removing the shared payload while another retained edge owns it.

## Equivalence argument and required closure

A same-final-source pre-layer variant is an honest extension of the reviewed omission method when the source proof is recorded explicitly. Normal and omissions start with identical frozen final sources, fixture and mandatory state. Each difference is one declared retained optional endpoint or named group and its real existing mandatory fallback. All disables their union in one process. It is not a historical commit or a recovered old binary. Record this source-equivalence argument and the exact endpoint registry in the existing plan before execution. The plan's pre-cache-baseline wording at452must not be silently reinterpreted by a measurement label.
