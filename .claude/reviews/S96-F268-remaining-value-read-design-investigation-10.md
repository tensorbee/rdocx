## Explicit bounded certificate state

The current BodyBlockScan cell at Native document.rs:9159stores one Option<StandaloneParagraphValue>, and that value at9186has one XML key and Weak<BodyContent>. It cannot cache many cell paragraphs without alternating keys and losing warm hits. Adding selectors to that single record does not solve the capacity/lifetime contract.

One finite possible replacement is a private active-root state containing a Weak root identity and a map from valid concrete selectors to one complete XML key each. The direct-body paragraph can have a distinct root-paragraph selector and remains a one-entry case. A table map is bounded by the finite set of actual paragraph selectors in its current immutable model. Selector construction and resolution must be private and structural, so arbitrary source strings cannot manufacture unbounded entries. No list of old keys, roots or model versions is allowed.

On a successful actual read and eligible complete leaf equality, install or replace that selector's sole key. If the active root differs, discard the entire prior root's entries before installing the new positive state. It is acceptable for concurrent old/new snapshots to evict each other's optimization. It is not acceptable to retain a map per historical root. A reader error remains uncached and propagates unchanged. A successful nonmatch does not create a positive entry. Exact clear/replacement behavior must be adopted for the multi-entry case without allowing old unrelated keys to become evidence for a new root.

All actual readers, finite qualification, equality and returned leaf cloning remain outside locks. Updates publish a fully constructed root/selector/key entry atomically under the metadata mutex. A hit still checks the live root, selector and complete key. Poison recovery must preserve safe actual-read fallback or an intact previously constructed positive entry, consistently with the existing policy. Missing root, wrong variant, invalid selector, stale/expired Weak, new model Arc, unsupported/private leaf or unavailable offered record cannot hit.

Root-model mutation or replacement must dissociate Weak identity through Arc::make_mut or supply a new Arc before any changed value can be observed. The factory's strong root/block references die with the factory. The retained state owns no table or CT_P, no Source receipt and no parent/child/root history. The actual mutable table/cell edit and reopen publishers need a caller audit and meaningful controls before implementation clearance.

Memory is an explicit cost. Observe root states, selector count, selector payload/capacity, key lengths/capacities and actual key/model copies.
