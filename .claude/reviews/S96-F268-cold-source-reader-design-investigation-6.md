## Admission is a separate blocker from model equivalence

Ordinary CT_Document::from_xml invokes admit_word_source at13640. Admission first qualifies actual constructor/capture behavior through admit_original_capture_records at9029 and then applies weighted input admission. OriginalCaptureWork::admit at8454 checks exact original capture work against retained_owner_work. The latter uses actual raw bytes and current captured context at `crates/rdocx-oxml/src/text.rs:30083`. Source admission separately checks recursive control/table costs at `crates/rdocx-oxml/src/document.rs:9444`.

The old child route admits a succession of wrapped inputs, each containing its own repeated head and tail. A full-part route admits a different single input with one root frame and all children. Per-child success is not a proof that aggregate capture work passes the whole-input bound. In particular, retained root metadata and namespace closure can be copied to many constructed owners. The source-work terms and repeated wrapper byte terms are not interchangeable. Known staged models, lexical Field exclusion and a model resource-depth proof do not establish that inequality.

Do not run the full reader, swallow a resource refusal and retry piecewise as though the failed whole attempt supplied no policy observation. Do not acquire a fresh scoped operation to reset or enlarge the admission. WordSourceFailure distinguishes resource and ordinary input internally at30, and admit_raw_word_source preserves that distinction at8905. Public ordinary errors convert both to OxmlError, so a string-based error classifier at the Native call site is not a valid replacement. Likewise, choosing whole prospective fallback can reject an input that the old positive piecewise path admitted. Calling it the existing authoritative fallback is not compatibility proof.

A viable provider contract must establish one of these boundaries before selection: the exact full input already has applicable actual whole-reader admission with unchanged identity and scope, or a finite eligibility proof guarantees the unchanged whole-input admission for the selected grammar and actual capture/context sizes. Writer proof is neither. If that proof cannot be stated for the original inputs without broader admission changes, retain the old reader and mark the optimization unselected. Actual whole-versus-wrapped boundary controls with large root metadata, many small children, raw capture and nested owners are required. They must not be described as observed counterexamples until executed.

## Physical mapping and reader semantics cannot be inferred

The existing record can contain bytes whose writer partition differs from the ordinary reader's constructed item sequence. A RawXml value can contain multiple physical elements, and an opaque wrapper may contain an inner body. Count equality or per-item serialization equality can accidentally match the wrong source ownership. CT_Body captures unknown and extra section elements as RawXml at13395 and13404, handles Empty elements separately at13412, and keeps the first section outside content at13386. Complete reader/event ownership matters.

A legitimate full-read batch must observe each actual direct-body construction boundary in the real CT_Body reader, including its original source range and output slot/kind. Every record child must correspond to exactly one completed actual output under one exact body frame. Account for all source bytes and all reader outputs, including section/tail metadata and any discarded/opaque input. Unsupported RawXml splits, inner-body ambiguity, nonclosed ranges, missing or duplicate slots, normalization mismatch and changed scopes leave the old route. No source range may be invented by serializing a model after reading it.

After that actual correspondence, retain each child's existing reader/writer round-trip requirement using the full reader's actual returned value and the same body_item_xml context. Compare complete relevant frame metadata and scope, not only body count. Do not lend staged values into ParsedChild. Positive locks contain only actual reader outputs under that exact frame. A failed, absent or wrong-scope proof remains unavailable, never a cached positive.

This suggests a finite hidden provider extension returning the ordinary parsed document plus an optional exhaustive actual body-read ledger. The ledger is an observer of the same substantive reader, not another parser and not a Source credit. All real body construction branches would have to populate or explicitly invalidate it. Its exact signature, sole Native consumer, error/resource semantics and HLD impact need adoption before source edits. The present ReturnedWordRead maps can inform that design but cannot be relabeled as this complete ledger.

## Cache, failure and identity contract still required

Gate the optimization to genuinely cold reader facts and the exact known current record/frame/partition. Lexical head/tail/blocks must be Field-free. Known actual or staged values must satisfy owner_facts_reusable_by_value. Unknown, failed or mismatched scopes and private Field/bookmark/tab-stop identities retain the old route and reader order. Raw/opaque correspondence requires the separate proof above even when the model's value-reuse predicate returns true.

The old route fills child proofs incrementally and can retain a successful prefix if a later child fails. Full admission happens before any new whole-reader model construction, and an ordinary whole read can also fail after a prefix. Existing scoped body read outputs are published only after successful completion at13459. Therefore an all-or-nothing batch that leaves every cache empty on failure does not preserve the old cache lifecycle. The provider contract must either preserve the actual successful prefix and first failure at the same logical boundaries or explicitly prove a permitted changed lifecycle. It cannot manufacture a positive prefix from a partial or failed whole parse.

Shared child empty-namespace proof effects must remain. After valid positive child proofs, preserve store_empty_namespace_owners and its exact positive/negative scope checks. Do not merely populate ParsedChild and claim the old preparation is complete. A staged value remains writer provenance. Source proof and namespace/reader caches remain independent.

There are also two live model sinks: the current reconstructed document and retained child.proved. One actual whole read does not make the required model ownership copy disappear. Move actual returned values into one sink and retain the necessary independent values in the other, using the existing representation. Avoid a new shared whole AST, retained history or broad ParsedChild representation change under an allocation-only label.

## Prospective fallback alternative and discriminators

Selecting the existing full-prospective-source fallback at the start of a cold attempt would skip current child reads and their cache effects. It also changes the actual admitted input and potentially Field/private allocation order and errors. Without the admission, mapping and lifecycle proof above it is not a smaller equivalent implementation. It remains needs-design, not an approved shortcut.

For any subsequently adopted finite batch, Native controls must compare complete old/new models, exact errors and all cache values/scopes before and after success and failure. Cover zero/one/many children, cold/warm/partially warm caches, first/middle/last failure, failed cached proof, poisoned scope, aliases/default/shadowing, root/background/section metadata, Empty versus expanded elements, split RawXml, inner bodies, controls, nested tables, Fields/bookmarks/tabs/private state and exact input/capture/resource boundaries. Source-reading failure must not acquire new credit through retry. Keep producer/source/writer separation and actual round-trip controls.

The public original25/100 reply must complete semantics, stale first-cause, held/fresh neighbors and save/reopen before mechanism assertions. A genuine predecessor should show56/139 actual current wrapped CT_Document reader calls at their real call sites, and a successor one actual current full-part read in that same bounded phase, only for qualified inputs. Count input bytes, actual parsed child facts, retained model copies, replacement reads, namespace preparation and every admission/mapping scan separately. The replacement child parser and parent standalone paragraph reads remain real work. Do not claim one parse for the entire reply or hide the qualifier scan behind a constant hit marker.

Compare complete predecessor packages and every part. Preserve all unsupported and unrelated-error fallbacks and the required cache fills. Scoped checking and independent review follow a closed adopted contract. Only a fresh authenticated ordinary shipping artifact with the unchanged elapsed protocol can establish performance benefit.
