## Owner and visibility modes

`XmlTree::snapshot_text(&self, revision_index:usize)->Result<String>` selects the actual qualified owner chain already identified by revision metadata. rPrChange selects its rPr parent and current r, pPrChange its pPr parent and current p, tblPrChange its tblPr parent and current tbl. sectPrChange and private package record are empty. Never select the previous properties stored inside the revision element. Other revision kinds select their own revision element.

Revision-local mode for insertion/deletion/move-from/move-to collects the selected element's text-bearing descendants once, preserving its own delText and its own move-from text. It does not suppress the selected deletion root using current-view policy. Nested revision text is not concatenated via both parent aggregate and child aggregate. Separate nested revision records can each report their own projection, but each record's string contains each selected atom once.

Property-current mode follows CT_P::accepted_text and CT_R::text (`text.rs:11948-11990`, `:12527-12539`, `:12621-12632`, `:5876-5908`): accepted insertion/move-to contribute, deletion/move-from content does not, and prior property snapshots never contribute. The current source identity/marker metadata, not local names alone, determines that removal. A whole table whose owned rows are all removed contributes no row text.

A paragraph-mark deletion/move-from does not erase the paragraph's inline text. The existing CT_Body::accepted_paragraph_joins_next (`document.rs:7712-7764`) affects body-line joining only when there is no section boundary and the immediately following item is an actual paragraph, table/control/raw/end adjacency does not qualify.
