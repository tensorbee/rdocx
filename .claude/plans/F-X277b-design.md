## Rejected alternatives

- Caller-supplied `ensure_hyperlink_style` as the way to satisfy A277-3. `Paragraph` has no style owner, and the registered outcome includes the low-level constructors.
- A document back-pointer on `Paragraph`. It would change every paragraph lifetime for a style id that publication can supply.
- Restyling every unstyled hyperlink on save. That rewrites imports and TOC result runs and breaks the case 7 regex.
- Retargeting `w:rStyle` to a style that is only named Hyperlink. The library keys styles by id, and the issue observation is the Hyperlink id.
- A public `RunContent::Separator`. `RunContent` is a public enum and this story adds no public signature.
- Writing donor separator spacing without native evidence, and treating that spacing as the acceptance criterion.
- Writing `w:footnotePr` and `w:endnotePr` for every new notes part. The issue excludes those lists. The policy API already owns them.
- Wrapping separator notes in revisions or giving them normal `StoryId`s. That is a second topology.
- Claiming imported footnote attributes survive `CT_Footnotes::from_xml`. The frozen parser drops them.
- Unifying `add_footnote` with the `create_*` smallest-free-from-2 rule. That changes today's separator-only result of 1.
- Putting numbering canonicalization at the start of `prepare_staged_output` and assigning that candidate back. Normalizing `save` and `to_bytes` would publish the remap into the live model.
- Permuting the live numbering model and then treating the rewritten integer as the handle. Id 0 and id 1 can swap in one space, so a lookup after the model is left rewritten is ambiguous. The maps are captured for the snapshot and the reopen, and the live model is restored before every return.
- Using Rust `Document::add_picture` or Rust `Document::add_footnote` as the A277-6 failure legs.
- Stopping numbering canonicalization on the emitted package. Equivalent construction orders would stop saving identical packages.
- Treating a foreign one-paragraph TOC as A277-7 or as an F-X273 dependency.
- Making literal replace update chart caches and workbooks together. The registered chart choice is to leave charts alone. Category edits stay on the chart-data API.
- Treating the chart fix as proof that replacement and `Document::text` agree for text boxes.
- Copying the donor's hash numbers onto this sprint HEAD. Those digests belong to a different base.
